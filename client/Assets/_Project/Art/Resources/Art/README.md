# Arte

Coloque aqui os sprites do pacote escolhido (Kenney, itch.io ou artista). O `SpriteCatalog` procura por nome;
o que não existir continua com o placeholder gerado em código.

Nomes esperados (PNG importado como Sprite, pivô no centro para tiles e na base para criaturas):

| Chave | O que é |
| --- | --- |
| `tile_floor`, `tile_wall`, `tile_exit`, `tile_spawn` | losango isométrico 2:1 (64×32 px por célula) |
| `chest`, `chest_open` | baú fechado / aberto |
| `ground` | pilha de cartas no chão |
| `hunter_0` … `hunter_3` | caçadores pelas 4 cores |
| `mark` | marcador do portador do tesouro |
| `monster_kobold`, `monster_skeleton`, `monster_spider`, `monster_orc`, `monster_mimic`, `monster_dragon` | monstros e chefe |
